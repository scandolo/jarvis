# Jarvis listening indicator explorations

These are preview mockups, generated with the built-in imagegen tool (not the
CLI). The selected A capsule is implemented in the app for listening, feedback,
and confirmations. Longer text expands the same capsule rather than switching
back to the old large panel.

## A · Capsula

Prompt: Polished macOS desktop screenshot mockup with two ordinary side-by-side
app windows, slightly blurred content, and a very small dark translucent
bottom-center capsule, roughly 180 × 34 points. Include a subtle green dot,
three tiny audio bars, and the exact text “Jev ascolta”. Strong contrast,
restrained native macOS styling, no oversized white card.

Selected revision: [a-capsula-v2.png](a-capsula-v2.png). Edited the original
mockup with the built-in imagegen tool to change only the label to the exact
text “Jarvis is listening”, widening the capsule only as needed while keeping
the dark high-contrast material, position, dot, waveform, and desktop intact.

## B · Linea

Prompt: Polished macOS desktop screenshot mockup with two ordinary side-by-side
app windows and only a thin luminous mint bottom-center audio line, roughly
150 × 4 points, with three gentle waveform peaks and a tiny “Jev” mark above.
Extremely minimal but visible, strong contrast, no large pill or white card.

## C · Orbita

Prompt: Polished macOS desktop screenshot mockup with two ordinary side-by-side
app windows and a small circular orb near the bottom center, roughly 46 points
